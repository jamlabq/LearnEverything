# OI Wiki 与 CS 自学指南的本站副本

用户明确要求复制两个仓库的 Wiki 内容并集成到 LearnEverything，而不是提供外链入口。

方案：完整保存两个仓库的 docs、原始导航配置、README 和许可声明，按固定提交构建本站 `/oi-wiki/` 与 `/cs-self-learning/`。使用 MkDocs Material 保留章节导航、目录、中文搜索、代码高亮、折叠说明、标签页和数学公式；CS 自学指南保留中英文切换。采用统一页头返回 LearnEverything，每页明确原作者、许可、来源提交以及本地适配说明。

与仅复制构建后 HTML 相比，保存源文件可以独立修改、校验和重新构建；与 iframe/外链相比，正文、资源和搜索实际由本站提供。保留仓库原始文件不改写，构建时在临时目录做链接与主题适配。

## 范围

- OI Wiki：465 个 Markdown 文件，以及 docs 下全部插图、示例代码和配套文件。正文遵循原项目 CC BY-SA 4.0 与 SATA 声明；代码和特殊标注保留原声明，不额外假定许可证。
- CS 自学指南：270 个 Markdown 文件（含英文），以及 docs 内全部资源，保留 MIT 许可及对第三方课程内容的许可边界。
- 将指向这两个 Wiki 已复制文章的绝对 URL、相对链接与站内导航解析为本站地址，支持 GitHub Pages `/LearnEverything/` 前缀。旧路径可在唯一匹配时映射，无法映射的明确记录。
- 页面依赖的主题、搜索、公式脚本与字体在本地提供。原有嵌入图片尽力下载并记录成功/失败；第三方大学课程、视频、外部书籍仍为原文参考链接。
- 不带入原站的评论、统计、在线编辑重定向和贡献者动态查询，保留其内容与作者信息。提供版本清单、哈希与可重复的构建/验证方式。
- 已有 FPGA、英语、WLAN 内容和未提交修改保留，首页只增加两个栏目。

## 验收

所有 Markdown 都有本站渲染页面；原始快照文件哈希匹配；逐页扫描内部链接及本地图片；浏览器在阻止外网的条件下验证正文、公式、示例代码、搜索、中英文切换、手机导航和返回首页。GitHub Actions 安装固定依赖并构建合并站点。不自动推送或发布。
