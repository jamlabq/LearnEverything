# English learning page — revised specification

用户授权在 `/work/hua2/projects/LearnEverything` 制作并修订静态学习页面。目标：理解、复述、临时回应，迁移到工作沟通、电视新闻和美剧；输入主题需要多样，不能只围绕职场。

## Accepted revision

- 45 个单元：10 短篇、5 过渡、25 篇 18–25 分钟完整长内容、5 个影视片段教学。
- 长篇包括 18 篇演讲、4 期双人播客与 3 期新闻专题；不以重复教学或合集总时长充数。
- 核心均有具体 B 站或 YouTube 视频链接；已找到的同内容 B 站版本附在对应卡片。另有 4 个影视拓展。
- 提供现成盲听→文本→讲解/跟读流程、具体章节跳转或明确的补练方法。
- 分别标注官方稿、非自动字幕、自动字幕；来源验证区分视频页元信息、正文读取、实际起播抽测和普通检索。
- 资源失败时不声称全部可播放。YouTube 核验用用户提供的代理，浏览器试播未成功；B 站 11 个视频完成起播抽测。
- 保留五步方法、每天 20/40/60 分钟安排、长篇分日训练、词组复习、真实对话与每五篇陌生材料验收。
- 主题/平台/文本类型与阶段、关键词、进度联合筛选。支持手机、键盘与深链接。
- 新课程使用 v2 存储，原 v1 保持不变并可导出带旧标题的笔记；不得将旧编号误映射到新材料。

延用静态 HTML/CSS/ES modules，无服务端账户或内置视频镜像。保持其它课程及并行 WLAN 变更。当前交付为本地可审阅页面，不自动提交或部署。

## Validation

Node 校验进度、旧记录隔离、长篇计数和资源证据；Playwright 校验 45 个单元、组合筛选、导出、存储失败/并发、四种尺寸和 Pages 路径。最后构建、查看截图、独立审查并检查差异。
