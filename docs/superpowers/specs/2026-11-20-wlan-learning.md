# WLAN 视频与文字学习导航

用户目标：把提供的视频清单完整收录到一个页面，并搜索补充篇幅可控的文字资料。以宏观理解为主，同时认识关键概念、软硬件分工和收发流程；不要求通读 IEEE 标准或整本教材。

## 页面方案

选择「五阶段路线 + 可搜索资料库」，兼顾首次学习和日后查找。单纯链接列表缺少阅读顺序；完整课程会超出本次资源导航的范围。

- 新增 `wlan/`，沿用仓库 HTML/CSS/原生 JavaScript 与 GitHub Pages 构建约定。
- 中文导读，保留原文标题；中英文资源均可收录，语言可筛选。
- 五阶段：全貌与接入、MAC 与 Linux、基带与 OFDM、射频与接收、软硬件贯通。每阶段指定视频与文字搭配，以及能讲清楚的问题。
- 资料卡包括媒体类型、来源、语言、主题、推荐程度、中文摘要、重点阅读范围、直达或搜索入口、链接核验说明。系列按一个资源组收录，列出用户提供的子标题。
- 交互：媒体/主题/语言/收藏筛选、全文检索、阅读指引展开、收藏与已学记录。记录仅在当前浏览器保存，存储不可用时仍可浏览。
- 页面内提供六步数据旅程及概念速查；明确控制路径和数据路径、SoftMAC/FullMAC、FFT 和译码、PHY 速率与有效吞吐的区别。
- 视觉：暖白底、深绿文字与强调色、轻分隔线、清晰字号与留白；桌面侧导航，手机顶部导航。资源无需外部字体、缩略图或播放器即可完整展示。

## 来源与边界

优先访问作者、官方文档、项目仓库与技术文章。教材只选相关章节并明确停止位置。视频无法确认 ID 时使用标注清楚的平台搜索入口，不能编造视频 URL、时长或字幕状态。核验需区别页面可访问与内容已确认；保存研究记录便于后续更新。

保留仓库已有英语课程及未提交更改。首页和 README 仅增补 WLAN 入口。本次不推送、不部署。

## 验收

用户清单中的所有视频或系列均有入口；文字覆盖连接过程、竞争与 ACK、Linux 栈、QAM/编码/OFDM、I/Q/RF、同步/均衡和完整实现。浏览器验证筛选组合、搜索空结果恢复、收藏与进度刷新保留、存储损坏降级、深链接、键盘使用和手机布局。静态构建能发布 `/wlan/`。
