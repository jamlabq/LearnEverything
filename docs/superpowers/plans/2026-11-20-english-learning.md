# English learning revision implementation plan

**Goal:** 多主题 45 单元，25 篇完整长原声，具体视频与可执行训练；真实呈现访问证据。

**Architecture:** 现有静态页面继续使用 HTML/CSS/ES modules；内容、证据、进度与 DOM 渲染分离。新版本隔离旧课程存储，旧记录只读导出。

- [x] 搜索 TED/BBC/Easy English 和影视教学；使用用户提供代理访问 YouTube，以浏览器搜索和抽测 B 站。
- [x] 核对原声时长、英文稿/字幕轨、频道与教学章节；产出 `resource-checks.json`。
- [x] 重编 10 短 + 5 过渡 + 25 长 + 5 影视，以及 4 个拓展；完善每课的主题和输出任务。
- [x] 更新页面文案、主题/平台/字幕筛选、逐链接证据、教学流程和长篇学习法。
- [x] 添加 v2 存储与 v1 旧标题导出，保留字段级保存和失败恢复。
- [x] 更新首页英语入口及文档，保持其它课程变更。
- [x] 运行 7 项 Node 测试和完整 Playwright：课程、证据、组合筛选、深链接、存储与旧数据、响应式。
- [x] 独立审查、最终 Pages 构建与预览验收。

独立复核未发现未修复问题；v1 导出及第 45 课保存重载另经独立浏览器检查。静态构建包含英语、FPGA 与 WLAN，预览入口和英语资源返回 HTTP 200。

当前验证结果详见 `english/README.md`；外部网络证据是一次性核验，不等于后续地区播放保证。
