# 把英语用起来 · 45 篇实战学习手册

目标是通过多主题理解、复述和即时回应，逐渐迁移到基本工作交流、新闻听力和生活美剧。工作交流是训练结果，不限制输入材料的题材。

## 学习路线

| 阶段 | 数量 | 材料与时长 |
| --- | --- | --- |
| 01–10 短篇热身 | 10 | BBC Learning English、TED-Ed、短演讲，3:10–6:29 |
| 11–15 表达过渡 | 5 | 沟通、关系、拖延与压力，9:44–14:15 |
| 16–40 长篇深听 | 25 | 18 篇 TED、4 期 Easy English 双人播客、3 期 BBC 新闻专题，18:01–24:29 |
| 41–45 影视精听 | 5 | Friends、Modern Family 的 B 站分步练习和 YouTube 教学课；教学时长独立标注 |

长篇按原始演讲或完整节目的时长计数，影视片段重复播放、讲解或合集总时长不计入 25 篇。主题覆盖心理、关系、饮食、科学、教育、文化、历史、科技与经济。4 个拓展入口补充影视分集、分段跟读与词汇课。

每课提供具体视频、英文文本类型、学习目标、输出任务、三条临时追问和自编练习句型。每篇完成盲听、精听、模仿、复述、交流五步；长篇理解全篇，重点模仿 3–5 分钟，练 3–5 分钟结构复述及 1–2 分钟简版。每五篇用陌生材料验收，每周安排真实对话。

## 资源核验

审阅日期：2026-11-20。证据摘要见 [`resource-checks.json`](resource-checks.json)，不保存临时签名媒体 URL 或登录数据。

- **B 站：** 11 个不同视频页完成浏览器起播抽测，含 6 个 TED、2 个核心影视练习和 3 个拓展。分 P 跳转另标“分 P 元信息已核对”，不是每个分 P 都试播过。已抽看两条核心分步练习的字幕阶段。平台可能要求登录或限制清晰度。
- **YouTube：** 44 个不同视频页通过用户指定代理核对标题、频道、时长、英文字幕轨和播放器 `OK` 状态，其中 43 个用于核心课程。浏览器试播未成功，页面没有声称“播放已验证”。具体网络和地区仍影响实际可用性。
- **TED：** 29 篇官方英文逐字稿正文已读取，记录了段落数与原始时长。YouTube 版本可能含更长的片头片尾。
- **字幕：** BBC Learning English 和部分教学课有非自动英文字幕轨；Easy English 播客、BBC 新闻、FluentU 这条影视课本次只找到自动英文字幕，必须核对数字、专名与难句。未把会员逐字稿承诺为免费文本。
- **教学流程：** B 站两条核心片段依据简介、标题及抽看片段；FluentU 依据明确的章节时间点，可直达 16:47 先盲听。其余教学课只说明已有词汇或发音讲解，并提示自行补齐盲听、复听。
- 搜索入口折叠展示，明确区别于具体视频。第三方视频不代表官方授权或持续可用。未采信“词汇暴涨”“96.2% 覆盖率”等宣传数据。

本站提供学习导航，不内置或镜像音视频。较早演讲和新闻用于语言练习，观点与数字需要结合其发表时间理解。

## 页面与记录

- 支持阶段、主题、视频平台、文本类型、进度的组合筛选及标题/讲者/来源搜索。
- `#lesson-1` 至 `#lesson-45` 直接打开课程；Escape 关闭详情，保留键盘焦点。
- 新版进度存入 `learneverything-english-v2`，按课程和字段分开保存。五步全部勾选计为完成，可撤销；同一笔记多个窗口以最后保存为准。
- **旧版保护：** `learneverything-english-v1` 保持原样，未把旧编号进度套到新材料。检测到旧记录时可导出带旧课程标题的 Markdown 存档。
- 没有账户、跨设备同步或自动导入。保存失败时保留当前页面草稿并提示导出；清除浏览器数据会删除记录。

## 本地预览

从仓库根目录运行：

```bash
python3 scripts/build_pages.py
python3 -m http.server 8000 --bind 127.0.0.1 --directory _site
```

打开 `http://localhost:8000/english/`。Pages 部署后的路径是 `https://jamlabq.github.io/LearnEverything/english/`；本地文件不代表已经部署。
