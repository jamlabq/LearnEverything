# FPGA 互动教程 Implementation Plan

> 执行方式：在当前会话逐项执行并自检。用户已确认前三课范围，无需再询问执行方式。当前目录是空目录且没有 Git 仓库，直接在用户指定目录交付。

**Goal:** 交付前三课完整中文互动教程和可运行的 Vivado 2022.2 实验。

**Architecture:** 无依赖静态网页；课程内容、布尔逻辑、交互电路、波形渲染分离。XSim 实验输出 VCD，再转换成静态数据供网页查看。

**Tech Stack:** HTML、CSS、原生 JS、SVG、Verilog/SystemVerilog、Tcl、Bash、Python、Playwright。

## Task 1 — 定义电路行为并验证

- [x] 创建 `tests/logic.test.mjs`：穷举 AND/OR/XOR/NOT 与 mux 的所有二值输入，核对 4 位二进制转换及非法输入。
- [x] 运行 `node --test tests/logic.test.mjs` 确认逻辑模块尚未提供。
- [x] 实现 `src/logic.mjs` 的 gate(kind,a,b)、mux(a,b,sel)、bitsToNumber(bits)，再次运行测试。

## Task 2 — 真实 HDL 实验

- [x] 为 `labs/01_parallel`、`labs/02_gates`、`labs/03_mux` 先编写自检 testbench，再实现可综合模块；使用 `#10` 保持输入后检查输出。
- [x] `scripts/run_labs.sh [all|01_parallel|02_gates|03_mux]` 检测工具并在 `build/` 内执行 xvlog/xelab/xsim，日志若有 ERROR/FATAL 或无 PASS 就失败。
- [x] `scripts/waves.tcl` 导出 VCD/WDB；`scripts/export_waves.py` 解析顶层信号和 ps 时间换算；生成 `src/lab-data.js` 并打包 `assets/fpga-labs.zip`。
- [x] `scripts/create_project.tcl` 创建 Vivado GUI 工程并设置设计顶层、仿真顶层和仿真时间。使用本机器件数据库验证。

## Task 3 — 完整课程与互动

- [x] `index.html` 提供语义化应用框架；`assets/style.css` 提供响应式设计和可访问焦点。
- [x] `src/content.js` 提供三课完整讲解、代码逐行说明、Vivado 操作步骤、练习及解释。
- [x] `src/simulators.js` 提供并行支路、逻辑门、四位计数表示、选择器图示与交互。
- [x] `src/waveform.js` 渲染手动事件与真实 XSim 波形；区分单位、标明理想行为仿真。
- [x] `src/app.js` 提供课程/面板导航、代码复制、练习反馈、进度保存和失败降级。

## Task 4 — 内嵌配图与交付

- [x] `src/simulators.js` 内嵌 SVG 表达代码→综合/实现→比特流→FPGA；另分支表示 testbench+RTL→XSim→波形。
- [x] 浏览器检查 SVG 的中文、连接线与不同屏幕尺寸。
- [x] `README.md` 提供网页启动、XSim 批处理、Vivado GUI、实验预期结果、排错和范围。
- [x] `scripts/start.sh` 启动本地服务；`tests/browser_check.py` 覆盖导航、开关真值、波形、测验与移动端。

## 验收命令

```bash
node --test tests/logic.test.mjs
bash scripts/run_labs.sh all
python3 scripts/export_waves.py
python3 tests/browser_check.py
```

浏览器截图、XSim 日志和 VCD 保存在 `build/`。按需求核对后给用户网页启动方式和教程入口。
