# FPGA 零基础互动教程：前三课

用户已选择“交互式网页＋配套 Vivado 实验”，并确认先完整制作前三课，检验教学风格。

## 教学目标与范围

面向没有 FPGA、数字电路和 Verilog 经验的读者，不要求开发板。完成前三课后，读者可以解释 FPGA 的可配置电路和并行工作方式，读懂二进制、与/或/异或/非真值表，理解二选一选择器，并在本机 Vivado 2022.2 / XSim 运行相应实验、查看波形与 RTL 电路。

1. 认识 FPGA：开关、信号、并行电路、HDL 与配置；用同一组输入驱动三条同时工作的逻辑支路。CPU 逐步执行是教学示意，不作真实性能比较。
2. 二进制与逻辑门：四位数位权、真值表、AND/OR/XOR/NOT；切换开关观察灯、电路和波形。
3. 选择器：两路数据、一根选择线；先预测、再切换选择信号，理解条件表达式代表电路连接。

后续七课只展示路线，不提供虚假的可点击课程。

## 页面与图示

中文、浅色纸张背景、深色电路实验台、青绿色强调色。桌面侧边课程导航，手机折叠导航。每课有学习目标、互动实验、原理图解、逐行代码与仿真步骤、带解释的练习；可保留本机学习进度。

演示使用 SVG，连线高低电平同时由颜色、0/1 标签和输出文字表达。波形可查看手动操作记录与真实 XSim 导出记录；明确手动记录以操作序号计，XSim 波形以 ns 计。教学图不虚构布局布线或物理延迟。按用户补充要求，所有图示直接内嵌 SVG，不使用 draw.io。

## 技术与实验

原生 HTML/CSS/JavaScript ES modules，无第三方运行时或联网字体，Python 标准库提供本地 HTTP 服务。三个实验各有可综合 Verilog、独立自检 SystemVerilog testbench。批处理统一执行 xvlog → xelab -debug typical → xsim，保存日志、WDB、VCD；Python 转换 VCD 为网页静态数据。图文明确区分 RTL 仿真、综合、实现、下载。Vivado Tcl 创建 GUI 工程，用户指定本机已安装器件，仿真不需要开发板。

## 验收

核心逻辑覆盖全部二值输入组合；testbench 断言失败时，脚本根据日志和 PASS 标记可靠报错。浏览器验证三课导航、键盘可操作开关、真值表联动、波形、测验反馈、进度保存、代码与下载、375px 和桌面布局。真实运行三个 XSim 实验并检查其波形与 JavaScript 逻辑一致。仅声称已验证的功能。
